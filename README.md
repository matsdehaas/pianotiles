# PianoTiles

Browser game made as a secondary-school programming project.

## Project

A Piano Tiles-style game implemented in vanilla JavaScript and HTML canvas. The original source is preserved with minimal changes.

## Run

Open `index.html` in a desktop web browser. The original HTML references `img/iphone7.png`, an asset that was **not present** in the recovered `PROGRAMMAS.rar`; the game layout may therefore look incomplete until that asset is recovered.

## Source and provenance

Original secondary-school coursework, rather than university coursework. No modern portfolio rewrite is included in this repository.
